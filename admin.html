Production setup

For real customers on different devices, connect this dashboard to Firebase Authentication + Firestore (or Supabase Auth + database). Browser localStorage is only a demo and is not secure payment access control.

  1. Create Firebase project.
  2. Enable Google + Email/Password authentication.
  3. Create Firestore collections for users and paymentRequests.
  4. Restrict the admin account with Firestore Security Rules.
  5. Replace demo data functions in admin.js with Firestore queries.
